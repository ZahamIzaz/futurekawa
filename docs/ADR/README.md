## Convention

- **Statut** : `Accepted` lorsqu'une décision est effectivement utilisée dans le POC.
- **Contexte** : problème ou contrainte à résoudre.
- **Décision** : choix retenu.
- **Alternatives** : options envisagées mais non retenues.
- **Conséquences** : bénéfices et compromis assumés.
